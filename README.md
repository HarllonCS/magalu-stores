# Magalu Stores

A simple front-end project developed to practice structural/visual layout with `<div>` and `<span>`, as well as applying styles using **internal CSS** (`<style>`) and **inline CSS** (`style="..."`).

The page simulates the layout of an e-commerce showcase/page inspired by **Magazine Luiza**, bringing together visual blocks such as a header, search bar, categories, product cards, and badges or text highlights. The focus is educational: understanding how to group layout blocks and highlight short snippets of text without relying on external CSS files or frameworks.

## Features

- **`<div>` (block-level container):** used to structure major sections and layout groupings, such as the header, product grid/row, and item cards.
- **`<span>` (inline conteiner):** used to highlight phone contact and footer.
- **Internal CSS (`<style>`):** defined in the `<head>` of the HTML document to apply reusable rules, such as font colors.
- **Inline CSS (`style="..."`):** applied directly to specific elements when a one-off adjustment or immediate variation is needed on a component.

## Tech Stack

- **HTML5**
- **CSS3**
